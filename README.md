# 📊 AI Business Insights Generator

An AI-powered Business Intelligence Dashboard built with **Python, Streamlit, Plotly, Pandas, and Groq Llama 3.3**.

This application helps businesses analyze sales datasets, generate AI-powered insights, visualize trends, and export professional PDF and Excel reports.

---

## 🚀 Features

- 📂 Upload any business CSV dataset
- 📊 Interactive Plotly dashboards
- 🤖 AI-generated business insights using Groq (Llama 3.3)
- 🌍 Regional & Country-wise analysis
- 📈 Revenue, Profit & Sales visualizations
- 📄 Export Business Report as PDF
- 📊 Export Filtered Dataset to Excel
- 🎯 Dynamic Dashboard Filters
- 🌙 Modern Dark UI

---

## ⚙️ Installation

```bash
git clone https://github.com/tanishkasaini55/AI_Business_Insights_Generator.git

cd AI_Business_Insights_Generator

pip install -r requirements.txt
```

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key_here
```

Run the project:

```bash
streamlit run app.
